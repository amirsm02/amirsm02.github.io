# Publication formatting

For every current or future publication on the home page, bold Amir's name in the displayed author list using `<strong class="publication-self">…</strong>`. Preserve the name spelling and author order from the publication (for example, `Amir S. Mohammadi`). Keep downloadable bibliographic records unformatted.

When changing the home page, check both light and dark themes and phone-sized layouts. Keep the theme toggle accessible by keyboard and preserve the saved preference behavior.
