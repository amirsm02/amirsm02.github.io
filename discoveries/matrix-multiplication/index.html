One fewer multiplication

The paper

AlphaEvolve: A coding agent for scientific and algorithmic discovery ↗

Alexander Novikov et al. / Google DeepMind

AlphaEvolve found an exact algorithm for multiplying two 4 × 4 complex matrices using 48 complex scalar multiplications, improving a 49-multiplication construction.

Exact construction + codeReleased 14 May 2025Sources checked 22 Oct 2026

01

What changed?

Before

49 scalar multiplications from applying Strassen’s construction twice.

The reported result

48 complex scalar multiplications for the same 4 × 4 task.

The conditions

Exact arithmetic over complex numbers; the metric counts scalar multiplications.

The limit of the claim

This does not prove 48 is minimal or guarantee a faster implementation on real hardware.

Source for the comparison ↗
02

What did the AI do?

AlphaEvolve / Gemini

Evolved a search algorithm that found the matrix decomposition.

Researchers

Researchers supplied the task, initial code and evaluation framework, then released the result.

What is disclosed: The technical report describes the pipeline; the public repository contains results and checking code, not AlphaEvolve itself.
